## 2) سجلّ الفرضيات H1–H7 (حالات مغلقة)

| ID | الفرضية | الحالة | الدليل / سبب الغياب |
|---|---|---|---|
| H1 | حقن الأعطال يكشف فشلاً غير مرئيٍّ في happy path | `OPEN` | بروتوكول: N=200 baseline vs N=200 بعطل محقون، فئات فشل ≥3 متمايزة. **لم يُنفَّذ** — لا عينة ولا أرقام |
| H2 | Progress Delta يبشّر بالعطب قبل الدرجة النهائية | `OPEN` | بروتوكول مكتوب. **لم يُنفَّذ** — لا تتبّع حالات مُسجّل |
| H3 | CPST يعيد ترتيب بدائل الوكيل مقارنةً بسعر النموذج | `OPEN` | يُقاس أسبوعياً على مجموعة مهام ثابتة. **لم يُنفَّذ** |
| H4 | فرق وكلاء AI-native تدفع مقابل تقرير جاهزية | `OPEN` | 10–15 مقابلة موثقة ثم 2–3 Pilots. **صفر مقابلات** موثّقة حتى 2026-09-09 |
| H5 | الاختبار الموسّع يولّد عبء حوسبة حقيقياً | `OPEN` | قياس compute لكل سيناريو. **لم يُقَس** — الرقم المطلوب قبل أيّ نقدٍ حوسبي |
| H6 | تكلفة التطوير الجزائرية فعلاً أقل | `OPEN` | مقارنة محاسبية داخلية بالمراجع. **لم تُثبَت** — لا تُدّعى ميزة قبلها |
| H7 | منهجية Coding Agents قابلة للتعميم | `OPEN` | Pilot ثانٍ في Workload آخر. **لم يُجرَ** |

**مجموعة الحالات المغلقة:** `OPEN` · `IN_PROGRESS` · `CLOSED_CONFIRMED` · `CLOSED_REFUTED` · `HOLD`.
⛔ `CLOSED_CONFIRMED` بلا ملف قياسٍ مؤرّخٍ في العمود الثالث = انتهاك L8.

## 4) ما لا يُعلن بعد — وسببُه

| ⛔ لا يُعلَن | السبب |
|---|---|
| ⛔ أيّ عميل أو عقد أو إيراد | لا دليل. القاموس الوحيد المسموح: `PROPOSED` / `DISCOVERY` |
| ⛔ أن السوق «50 مليار» | تقديرات محللين متفاوتة (5.2→52.6 أو 2.6–7.3→24.5–48.2) — تُنسب لمصدرها وتاريخه وتُوسم `MARKET HYPOTHESIS` |
| أن مركز وهران متاح | حدثٌ موثقٌ (حجر أساس 2025-03) وليست قدرةً؛ لا طاقة/سعر/توفر معلنة |
| أن السيادة ميزة تنافسية | خيارُ نشرٍ يشترى بالمتطلبات؛ منافسون يقدّمون نشراً سيادياً فعلاً |
| أن LangGraph هو المنتج | محوّلُ أولٍ عميقٌ؛ النواة مستقلةٌ — و⛔ لا وصفٍ لها كمنصةِ إطارٍ معيّن |
