## 4) نتيجتان محسوبتان تُعلنان (🟢⟨ح⟩)

1. **بروتوكول H1 المُعلن (N=200) ناقصُ القدرة لأثر ٥ نقاط مئوية**: الفاصل عند N=200
   هو [−0.015، 0.116]، وأصغرُ N حاسم = ٤٠٠. التوصية: إعلان MDE قبل التنفيذ.
2. **أجل الترحيل قيدُ تصميم عقد**: بتشتّتٍ مُعلن (p90 = 1.8 × p50) وأجل ١٢٠ يوماً،
   Net-60 → خطر ٦.٥٪ (`ELEVATED`) وNet-90 → ٢٦.٥٪ (`SEVERE`)؛ وأقصى p50 لخطر ≤ ٥٪
   هو ٥٦.٤ يوماً.

كلتاهما **حسابٌ حتمي** في `VERA_MEASUREMENTS.json`، وليستا قياساً على عميل.
