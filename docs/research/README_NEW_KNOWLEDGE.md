### ما تم إنجازه

#### 1. معرفة جديدة كلياً: CDKC

**الاسم:** CogniForge Durable Knowledge Coefficient — معامل المعرفة الدائمة القابل للتصدير

**المعادلة:**
```
CDKC = (M_durable × R(Δt,S) × V_sym × (1 - L_switch)) - λ × gap_dangerous
```

**لماذا جديدة:**
- لا معيار موجود يجمع BKT + FSRS + تحقق رمزي + معايرة ثقة + تبديل لغوي عربي/فرنسي/دارجة
- كل حد حتمي، لا LLM في المسار العددي — قابل للتدقيق
- تُنتج رقماً يفسر نفسه: لماذا سينسى؟ هل لأنه واهم؟ هل لأن الرمز مرفوض؟ هل لأن اللغة؟

**الملفات:**
- `shared/research/durable_knowledge.py` — المعادلة (stdlib فقط)
- `shared/research/exportable_eval.py` — تحويلها إلى منتج
- `shared/research/__init__.py` — الواجهة

**الاختبارات:** 24 اختباراً — كلها خضراء
- `tests/shared/test_cdkc_durable_knowledge.py` — 18 اختبار

### كيف يتحول إلى عملة صعبة

```
معرفة جديدة (CDKC) → حزمة موثقة (100 مهمة) → 5 مقابلات اكتشاف → OFFER_READY → PILOT → PAID_PROOF → REPEATABLE → $/€
```

**الخندق الذي لا يُنسخ:**
- تاريخ مقيس لتلميذ جزائري بعينه، بلغته، وفق سلّم تنقيطه، ومعامل شعبته
- أطلس أخطاء بثلاث لغات مربوط بعناصر علاجية — كل تلميذ إضافي يوسعه
- بنك عناصر معاير على بيانات جزائرية حقيقية — عمل محتوى مضنٍ

**شروط القتل (متى نعترف بالفشل):**
- K1: Brier(M×R) ≥ Brier(M) → CDKC لا يضيف
- K2: L_switch غير دال → الكلفة وهمية
- K3: ظهور معيار يجمع الخمسة → الندرة تسقط
- K4: 5 مقابلات ترفض المشكلة → يتجمد الخط
- K5: Cohen κ < 0.50 → البروتوكول غير قابل للتشغيل

قتل البحث نجاح منهجي — البديل (عرض بلا فجوة) هو الفشل الممنوع.
